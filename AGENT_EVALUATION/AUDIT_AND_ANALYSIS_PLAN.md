# Agent 审计与统计分析计划

## 1. 分析目的

本计划旨在评价双 Agent 证据评价流程能否以较低的人工干预，准确且稳定地执行
DRRL/ERL 协议。该计划不以模型排名为主要目标，也不验证 ERL 对目标工程案例的预测效度。

## 2. 样本设计

### 2.1 32 家族五模型审计

- 每 Cluster 8 家族；
- 目标为 4 `include` + 4 `provisional`；
- 至少 8 个多版本、派生或复合家族；
- 排除阶段 0 使用的 8 个试运行家族；
- 每个家族选择一个代表性发布/任务评价单元（sentinel unit）；
- 在任何正式评分开始前，根据已固定的注册表和公开哈希算法确定样本。

代表性评价单元的选择优先级为：官方稳定发布、Cluster 主任务原生标注、最新明确发布，并以哈希
值解决同优先级情形。不得依据预估或正式等级选择。

### 2.2 五组证据评价流程

每个审计家族，五个模型各担任一次检索者和一次核验者。核验偏移量
`d=1,2,3,4` 各分配 8 个家族：

\[
P_i \rightarrow P_{1+((i-1+d)\bmod 5)},\quad i\in\{1,2,3,4,5\}
\]

在每个 Cluster 内尽量平衡偏移量。每个家族的预定主有向对必须包含在其五组审计
证据评价流程之一。

以上 32/16 设计完整适用于 DRRL。ERL 仅对满足资产可评性条件的发布—任务单元执行，
因此其附加运行量和审计覆盖使用 \(N_E\)、\(N_{EA}\)、\(N_{ER}\) 参数化报告，
不得与 DRRL 在同一角色执行中合并评价。具体公式见主协议第 11.4 节。

### 2.3 16 家族重复审计

从 32 家族内按独立哈希选择每 Cluster 4 个，目标为 2 `include` + 2
`provisional`。沿用首次相同的 `d`，并在新 `replicate_id` 和相互独立的新上下文中，完整
重复五组证据评价流程。同一 `run_id` 内使用相同的预先固定网络响应。

## 3. 人工参考

### 3.1 覆盖范围

- 32 个代表性评价单元的全部等级相关字段；
- 许可、访问、身份、版本、适用性以及所有必要性判据字段；
- 非等级描述字段按预登记的确定性分层样本；
- 不使用目标工程案例性能。

### 3.2 人员与盲化

- Cluster 学生主核验；
- 第二学生轮换复核全部等级相关字段和抽样描述字段；
- 两人对模型身份、Agent 输出和 Agent 等级盲法；
- 人工分歧由项目负责人统一裁决；
- 人工参考结果预先固定后，方可与 Agent 输出进行匹配分析。

人工参考仅用于评价 Agent 准确性，不得用于修改 Agent 原始结果或主评价流程等级。

## 4. 主要终点

### 4.1 来源与字段层

1. 相同权威主来源发现率；
2. 标准化字段值精确一致率；
3. 预声明连续字段的容差一致率；
4. 证据终态一致率；
5. 错误引用率；
6. 必填证据遗漏率；
7. 来源—声明不匹配率；
8. 错误确定结论率；
9. 冲突与合理弃答率；
10. `RUN_INCOMPLETE` 与恢复率。

### 4.2 解析覆盖与准确性

对人工参考可判定字段：

\[
Coverage=\frac{N_{agent\ determinate}}{N_{reference\ resolvable}}
\]

\[
ConditionalAccuracy=\frac{N_{correct\ determinate}}{N_{agent\ determinate}}
\]

\[
OverallCorrectResolution=\frac{N_{correct\ determinate}}{N_{reference\ resolvable}}
\]

Agent 的 `UNRESOLVED_AFTER_REVIEW` 降低 Coverage 与 OverallCorrectResolution，
但不进入 ConditionalAccuracy 的错误分子。人工参考本身不可判定的字段不进入
值准确率分母，但单独报告参考不可判定率。

### 4.3 一致性

- 名义分类状态：Gwet's AC1 或 Krippendorff's alpha；
- 有序状态/等级：Gwet's AC2 或有序 alpha；
- 字段值：精确/容差一致率；
- 最终等级：次要终点，不替代字段和证据终点；
- 测试—重测：按模型与角色报告一致率和系数。

## 5. 统计单位与不确定性

主要统计单位为数据集家族的代表性评价单元。字段、模型、模型对和重复测量均嵌套于家族之内，
不得作为独立数据集增加样本量。

- 按 Cluster 分层；
- 以家族为单位 bootstrap；
- 报告点估计和置信区间；
- 家族内部所有字段/模型记录随该家族一同重采样；
- 不把多版本/复合产品当作独立家族；
- 不以大量字段产生的窄置信区间替代家族级不确定性。

主要分析以估计为主，不围绕 `p<0.05` 组织多模型排名。若探索模型、角色、Cluster
或来源类型差异，必须标为探索性并控制多重比较叙事。

## 6. 主分析结果与敏感性分析结果

- 主分析结果：每个家族预先指定 `primary_pipeline`；
- 五模型可靠性：32 个家族的五组证据评价流程；
- 重复性：16 个家族的第二次独立执行；
- 探索性证据并集：联合五组流程的已核验证据，仅用于敏感性分析；
- 人工参考替代评分：仅用于评价 Agent 误差，不替代正式主分析结果。

审计家族不得因额外模型评价而获得更高的正式等级。

## 7. DRRL/ERL 结果分析边界

- 98 家族全部报告 DRRL；
- 全部家族报告 ERL 资产可评状态；
- 只有可评发布/任务单元报告 ERL；
- 未评 ERL 不赋最低值；
- 不生成 DRRL+ERL 总分；
- DRRL–ERL 具体联合分析等正式结果支持度明确后决定，并明确标记探索性。

发布/任务单元结果全量保留；总体比例和置信区间按家族聚类、家族等权。

## 8. Agent 方法贡献分级

不设置缺乏理论依据的单一“创新及格线”。根据预登记终点和置信区间分级表述：

| 结果形态 | 允许表述 |
|---|---|
| 高准确、高覆盖、高跨模型一致性、高重复性，Cluster 无系统失效 | 经经验验证、可复用的双 Agent 评价方法 |
| 总体可用但局部不稳 | 具有可行性证据的半自动评价框架 |
| 准确或覆盖不足 | 透明实验执行工具，不作为独立方法创新 |

所有情形均公开失败类型、适用边界和不确定性。
