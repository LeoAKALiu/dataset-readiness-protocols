# Cluster A 复用核验字典：二维基础设施表面/结构病害影像

## 0. 文档角色与边界

本字典将 DRRL 主协议中的 C2.6 和 C4.2 具体化为可执行的核验项，用于核验独立第三方能否无歧义地解析并接入二维病害影像数据。

本字典只评价复用就绪度，不评价：

- 病害类别或工程工况覆盖是否充分；
- 标注是否足以支持工程域迁移；
- 数据是否存在捷径、长尾或域偏移风险；
- 模型在真实工程案例上的 zero-shot 表现。

上述内容属于独立 ERL 协议。相同证据可以被两套协议分别引用，但不得继承判据状态。

## 1. 适用范围

适用于二维 RGB 基础设施表面或结构病害影像。评级前必须冻结任务分支：

- `A-CLS`：单标签或多标签分类；
- `A-DET`：目标检测；
- `A-SEMSEG`：语义分割；
- `A-INSSEG`：实例分割。

一个发布物包含多个任务分支时，应分别执行任务专用检查，不得以其中一个分支的可用性代表其他分支。

RGB-T 配对数据属于 Cluster B；城市资产识别属于 Cluster D。

## 2. 评级前冻结项

至少冻结：

1. 数据集身份、版本和复用范围；
2. 任务分支及适用的标签类型；
3. 官方发布清单或评价者生成的冻结文件清单；
4. 图像格式、色彩空间、通道顺序和方向处理规则；
5. 类别表、类别 ID、背景、忽略值和负样本语义；
6. 标签坐标约定或掩膜编码；
7. 原图、裁块、缩放图及派生标签之间的关系；
8. 官方划分是否存在及其重建方法；
9. 确定性探针样本集 `S_probe`；
10. 中立接入环境和允许的依赖。

## 3. 最小中立数据对象

Cluster A 的最小接入对象至少包含：

```yaml
sample_id:
image_uri:
task_subtype:
annotation_uri:
class_ids:
image_width:
image_height:
image_encoding:
split:
source_sample_id:
transform_trace:
physical_scale:
```

`source_sample_id`、`transform_trace` 和 `physical_scale` 按发布声明确定适用性。若发布方没有提供相应语义，不得凭文件名或像素外观猜测。

## 4. 执行范围与抽样

- 文件存在性、标识符唯一性和引用关系优先对完整清单执行全量核验。
- 载荷解码使用预先冻结的 `S_probe`。样本集至少覆盖所有任务分支、文件格式、划分和标签编码变体。
- 若数据规模导致无法全量下载或解码，必须记录 `verification_scope`、抽样算法、随机种子或哈希规则及未核验范围。
- 抽样通过只能支持声明范围内的结论，不得表述为“所有文件均有效”。
- 发现任一会导致系统性误解析的关键反例时，不得用总体成功率掩盖。

## 5. 条件核验项

| 核验 ID | 核验对象与执行操作 | 原始输出 | 通过规则 | 对应主判据 |
|---|---|---|---|---|
| A-RV1 | 建立图像、标签和样本 ID 清单，解析全部已声明引用 | 图像数、标签数、孤立文件数、悬空引用数、重复 ID 数、引用解析率 | 适用范围内无会阻止样本构建的悬空引用或身份冲突 | C2.2、C2.4 |
| A-RV2 | 在中立环境中解码 `S_probe` 图像，并核对宽高、通道、色彩和方向 | 解码成功率、实际形状、通道数、方向修正记录、失败清单 | 所有必需格式均有成功实例；不存在未说明且会改变标签几何的方向或尺寸处理 | C2.3、C2.4 |
| A-RV3 | 解析类别表、类别 ID、背景、忽略值和负样本语义 | 类别映射表、未定义 ID、冲突 ID、未知值清单 | 所有实际出现的标签值均能映射到已声明语义或明确的忽略规则 | C2.3 |
| A-RV4 | 按冻结任务分支解码标签，并将其映射回图像坐标 | 成功样本数、失败样本数、越界对象数、空标签解释、可视化核验产物 | 标签表示可被唯一解释；坐标或掩膜规则不会产生系统性错位 | C2.2、C2.4、C2.6 |
| A-RV5 | 如存在官方划分，按发布规则重建样本集合 | 各划分 ID 集、缺失 ID、重复归属 ID、重建配置哈希 | 官方划分可唯一重建，且样本身份与发布物一致 | C2.5 |
| A-RV6 | 如存在裁块、缩放、旋转或格式转换，恢复派生样本到源样本的变换链 | 可追溯派生样本数、不可追溯样本数、变换参数和来源 ID | 所有影响标签解释的关键变换均可记录并重复执行 | C3.1、C3.2 |
| A-RV7 | 将 `S_probe` 转换为最小中立数据对象，并执行最小读取、索引和批供给 | 生成对象数、字段缺失、适配器日志、阻塞和修复清单 | 无未公开知识即可构建并读取全部必需字段 | C4.1、C4.2、C4.4 |
| A-RV8 | 使用相同输入、环境和配置重复生成中立对象 | 清单哈希、字段哈希、对象计数差异、顺序差异 | 除预先声明的非确定字段外，两次输出一致 | C4.3 |
| A-RV9 | 发布方提出基线或性能声明时，核对任务、版本、划分、预处理和指标并执行复现 | 声明映射表、运行日志、结果、容差裁决 | 满足主协议冻结的条件性复现规则；无基线声明时为 `N/A` | C3.3—C3.5 |

## 6. 任务专用解析规则

### 6.1 A-CLS

- 明确单标签与多标签语义；
- 明确负样本、无病害样本和缺失标签的区别；
- 明确类别顺序、稀疏/稠密编码和标签文件分隔规则。

### 6.2 A-DET

- 明确框格式，例如 `xyxy`、`xywh` 或中心点格式；
- 明确坐标原点、像素边界是否闭合、归一化方式；
- 明确截断、忽略、拥挤密集区域（`crowd`）和无目标影像规则。

### 6.3 A-SEMSEG

- 明确掩膜像素值、调色板与类别 ID 的关系；
- 明确背景、忽略值和无效区域；
- 明确插值规则，禁止对离散标签使用会产生新类别值的插值而不说明。

### 6.4 A-INSSEG

- 明确类别 ID 与实例 ID 的编码方式；
- 明确重叠、遮挡和实例边界冲突的处理；
- 明确实例表与掩膜或多边形之间的引用关系。

## 7. 状态裁决与异常处理

- 实际解码或引用解析失败记为 `FAIL`，不得由文档声明覆盖。
- 仅缺少足以核验的信息且未观察到确认失败时记为 `UNKNOWN`。
- 某任务分支、划分、派生链或物理尺度确实不适用时记为 `N/A`，并记录依据。
- 第三方自行猜测坐标、类别或方向后得到“看似正确”结果，不得判为通过。
- 评价者制作的修复脚本必须保留原始失败、修复内容和人工时间；修复后的成功不得抹去摩擦事件。


```text

```

## 9. 禁止做法

- 用随机打开少量“正常图片”替代冻结探针集；
- 根据文件名猜测标签对应关系后判为通过；
- 把图像可显示等同于标签可正确解析；
- 忽略 EXIF 方向、裁块来源或坐标约定；
- 用第三方修复后的发布物替代原始发布物评级；
- 将类别覆盖、标注准确率、近重复率或模型性能写入 DRRL 等级计算；
- 使用目标工程案例选择解析规则或复现容差。
