# Cluster C 复用核验字典：三维城市/基础设施点云

## 0. 文档角色与边界

本字典将 DRRL 主协议中的 C2.6 和 C4.2 具体化为可执行的核验项，用于核验独立第三方能否正确解释、解析并接入三维点云发布物。

本字典不评价：

- 点密度、空间覆盖和类别覆盖是否充分；
- 配准残差、运动畸变或标注质量是否满足工程要求；
- 数据是否能够跨传感器或跨地区 zero-shot 迁移；
- 模型在点云任务上的性能。

这些问题属于独立 ERL、数据质量审计或模型评价。

## 1. 适用范围

适用于三维城市或基础设施点云的：

- 语义或实例分割；
- 三维目标检测；
- 变化检测；
- 工程几何测量。

评级前必须冻结任务分支。二维图像投影产品若不能追溯到三维点云，不属于本字典的三维接入对象；RGB-T 属于 Cluster B。

## 2. 评级前冻结项

至少冻结：

1. 点云文件格式、压缩方式、字节序和解码器；
2. 点记录字段名称、顺序、类型、缩放和缺失值；
3. 坐标参考系、轴顺序、长度单位、原点和偏移；
4. 标签单位：逐点、逐对象、体素、网格或场景；
5. 类别 ID、忽略值和未标注点语义；
6. 场景、条带、扫描站、切块和源测区之间的层级；
7. 配准、拼接、去噪、下采样、体素化和切块转换；
8. 官方划分及空间或采集分组方式；
9. 确定性场景探针集 `S_probe_scene`；
10. 中立评价环境和参考点云对象格式。

```yaml
scene_id:
```

坐标参考、单位或原点确实不适用于局部归一化任务时，必须明确说明局部坐标的构造方法；不得仅凭坐标数值范围猜测物理单位。

## 4. 执行范围与抽样

- 文件身份、场景—标签引用、字段模式和划分归属优先对完整清单执行全量核验。
- 点载荷解码使用冻结的 `S_probe_scene`，至少覆盖全部文件格式、字段模式、任务分支、划分和不同层级的场景/切块。
- 不得把随机训练窗口、重复切块或点的数量当作独立核验对象；探针单位应是原始场景、条带或可追溯切块。
- 如无法全量读取超大场景，允许使用公开格式支持的分块或流式读取，但必须记录读取范围和未核验部分。
- 发现系统性字段错位、单位歧义或标签长度不一致时，不得用大多数文件的成功记录加以掩盖。

## 5. 条件核验项

| 核验 ID | 核验对象与执行操作 | 原始输出 | 通过规则 | 对应主判据 |
|---|---|---|---|---|
| C-RV1 | 识别并解码点云文件格式、压缩和字节序 | 文件格式清单、解码成功率、点数、失败文件和依赖 | 所有必需格式均有可重复的公开解码路径，实际点数与头信息或清单一致 | C2.3、C2.4 |
| C-RV2 | 解析点字段模式、类型、顺序、缩放、偏移和缺失值 | 字段表、实际类型、未定义字段、字段冲突和数值解码样例 | 所有被任务或标签依赖的字段均可唯一解释 | C2.3、C2.6 |
| C-RV3 | 解析坐标参考、轴顺序、单位、原点和局部/全局转换，并执行坐标转换样例 | CRS、单位、轴、偏移、转换链和执行日志 | 第三方能够确定坐标语义并重复执行已声明转换；本项不判断空间覆盖或几何精度 | C2.3、C2.6、C3.1 |
| C-RV4 | 建立点云、标签和对象/体素引用，核验标签长度或索引 | 点数、标签数、无标签点、越界索引、未定义类别和引用解析率 | 标签单位和对应关系能够唯一重建，不存在阻止任务对象构建的系统性错位 | C2.2、C2.4、C2.6 |
| C-RV5 | 解析场景、条带、扫描站、切块和源测区层级，并核验重组或去重语义 | 层级图、父子引用、重叠/边界规则、不可追溯切块数 | 派生块能够追溯到源场景；重叠点、边界和拼接规则可解释 | C2.2、C3.1 |
| C-RV6 | 解析配准、拼接、下采样、体素化和裁块等关键转换链 | 转换参数、工具/代码、输入输出映射和无法重建步骤 | 所有会改变坐标、点身份或标签关系的关键步骤均可记录并重复执行 | C3.1、C3.2 |
| C-RV7 | 如存在官方划分，按发布规则重建场景或空间组 | 划分 ID、缺失 ID、重复归属、空间/采集分组字段和配置哈希 | 官方划分能够唯一重建；本项不评价划分是否具有 ERL 所需的域隔离质量 | C2.5 |
| C-RV8 | 将 `S_probe_scene` 转换为最小中立点云对象，并执行场景读取、索引和批供给 | 对象数、点数、字段缺失、适配器日志、阻塞和修复 | 无未公开知识即可取得任务所需的坐标、属性、标签和层级字段 | C4.1、C4.2、C4.4 |
| C-RV9 | 相同输入、环境和配置下重复生成中立点云对象 | 清单哈希、字段哈希、点数和顺序差异 | 除预先声明的非确定排序外，重建对象在内容语义上等价 | C4.3 |
| C-RV10 | 存在公开基线声明时，核对版本、点字段、预处理、体素/切块、划分和指标并执行条件性复现 | 声明映射、日志、结果和容差裁决 | 满足主协议冻结的条件性复现规则；无声明时为 `N/A` | C3.3—C3.5 |

## 6. 关键语义规则

### 6.1 点数字段必须逐项声明

至少区分坐标、颜色、强度、回波、法向、时间、环号和用户自定义字段。字段存在但单位或编码未知时，不得因加载器未报错而判为可解释。

### 6.2 坐标可解释不等于工程精度充分

DRRL 要求坐标、单位和变换可重复解释。尺度误差、配准残差和工程测量精度由 ERL 或专门计量协议评价。

### 6.3 切块不是独立来源

若发布物由原始场景切块产生，必须保留父场景身份、块边界和重叠处理规则。能读取独立块但无法恢复其来源时，C-RV5 不得通过。

### 6.4 标签长度相等不是充分条件

逐点标签必须与点顺序或稳定点 ID 对齐。仅因为点数与标签数相同，不得据此认定排序和身份一致。

## 7. 状态裁决与异常处理

- 单位、轴顺序或原点只能依靠猜测时，依赖这些信息的检查记为 `UNKNOWN`。
- 文件可打开但必需字段错位、类型错误或标签无法对齐时，相关执行项记为 `FAIL`。
- 没有官方划分时 C-RV7 为 `N/A`；不得由评价者临时划分后声称复现官方结果。
- 不涉及全局物理坐标的局部归一化任务可以将全局 CRS 记为 `N/A`，但局部坐标生成规则仍须可解释。
- 第三方修复头信息、字段顺序或标签索引时，必须记录原始失败、修复脚本和摩擦。

## 9. 禁止做法

- 依据坐标数值范围猜测长度单位（米、厘米或毫米）或轴顺序；
- 把文件可打开等同于点字段和标签语义正确；
- 仅凭点数相同断言逐点标签已对齐；
- 把训练窗口或随机裁块当作独立场景核验；
- 忽略局部坐标、全局坐标和原点偏移之间的转换；
- 用第三方重写的头信息或标签文件替代原发布物评级；
- 将点密度、空间覆盖、配准质量、标注精度或模型性能写入 DRRL 等级计算；
- 使用目标工程案例决定体素、切块、坐标或复现规则。
