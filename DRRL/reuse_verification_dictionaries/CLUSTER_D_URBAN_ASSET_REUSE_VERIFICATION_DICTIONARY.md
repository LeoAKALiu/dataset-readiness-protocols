# Cluster D 复用核验字典：城市资产与城市场景数据

## 0. 文档角色与边界

本字典落实 DRRL 主协议中的 C2.6 和 C4.2，用于核验独立第三方能否正确解释、关联并接入城市资产与城市场景发布物。

本字典只评价复用所需的数据结构和关系是否明确、可执行，不评价：

- 城市、天气、设备或资产类别覆盖；
- 小目标、遮挡或长尾标注质量；
- 地理或背景捷径风险；
- 跨城市或跨设备工程迁移表现。

上述内容属于独立 ERL 协议。

## 1. 适用范围

Cluster D 至少包含以下可单独适用的任务分支：

- `D-Det`：二维城市场景中的城市资产检测；
- `D-Seg`：城市场景或资产语义分割；
- `D-InsSeg`：城市资产实例分割；
- `D-Link`：影像、空间几何、资产台账或时序观测之间的身份关联。

一个发布物包含多个任务分支时，必须分别冻结适用性和执行检查。

纯三维点云属于 Cluster C；RGB-T 配对数据属于 Cluster B。仅当发布物声称提供地理定位、资产身份或多源关联时，相关条件检查才适用。

## 2. 评级前冻结项

至少冻结：

1. 任务分支和最小资产/场景对象；
2. 图像、标签、矢量、表格和其他数据文件格式；
3. 类别、实例、背景、忽略区、crowd、遮挡和截断语义；
4. 资产 ID、观测 ID、路线/序列 ID 和跨表引用键；
5. 空间参考系、轴顺序、坐标单位和几何类型；
6. 时间字段、时区、采集批次和版本语义；
7. 多视角、多帧、街景序列和同一资产观测之间的关系；
8. 官方划分和组级重建规则；
9. 确定性探针集 `S_probe_asset`；
10. 中立评价环境和参考城市资产对象格式。

## 3. 最小中立数据对象

```yaml
observation_id:
asset_id:

annotation_uri:

class_ids:

geometry_type:
coordinate_reference:
```

`asset_id`、空间几何、时间和关系记录按任务声明确定适用性。二维匿名场景数据没有资产身份时可以记为 `N/A`，但不能据此声称支持资产级关联。

## 4. 执行范围与抽样

- 文件、观测、资产和跨表引用优先基于完整清单执行全量关系核验。
- 载荷解码和关系遍历使用冻结的 `S_probe_asset`，至少覆盖全部任务分支、格式、划分、几何类型、关系类型和已声明异常状态。
- 存在视频、街景、多视角或多源表时，探针集必须包含完整关系组，不能只抽取孤立的成功帧。
- 如只能访问部分城市或分片，必须记录获取边界，不得把局部成功表述为整个发布物可集成。
- 任何会导致资产串号、坐标误解或跨表错配的关键反例均视为系统性阻塞，不能由平均成功率补偿。

## 5. 条件核验项

| 核验 ID | 核验对象与执行操作 | 原始输出 | 通过规则 | 对应主判据 |
|---|---|---|---|---|
| D-RV1 | 识别任务分支、最小对象和各文件角色 | 任务—文件—对象映射、未知文件角色和任务冲突 | 第三方能够确定每个任务的输入、标签单位和输出对象 | C2.2、C2.3 |
| D-RV2 | 建立影像/媒体、标签和观测 ID 清单并解析引用 | 媒体数、标签数、观测数、孤立文件、悬空引用、重复 ID 和解析率 | 适用范围内不存在阻止样本构建的身份或引用冲突 | C2.2、C2.4 |
| D-RV3 | 按 D-Det、D-Seg 或 D-InsSeg 解码类别、实例和几何标签 | 类别映射、未定义 ID、越界几何、忽略/crowd/遮挡/截断编码和失败清单 | 标签表示可被唯一解释并映射到媒体坐标 | C2.3、C2.4、C2.6 |
| D-RV4 | 发布物声称存在稳定资产身份时，核验 `asset_id` 的唯一性、作用域和跨观测引用 | 资产数、重复/冲突 ID、无主观测、一对多关系和资产解析率 | 资产身份作用域明确，关系可由公开键重建；不适用时为 `N/A` | C2.2、C2.6 |
| D-RV5 | 发布物提供空间几何时，解析 CRS、轴顺序、单位、几何类型和影像/资产空间关系 | CRS、单位、几何有效性、转换链、未知或冲突坐标记录 | 第三方能够重复解释和转换已声明空间信息；不判断定位精度是否满足工程要求 | C2.3、C2.6、C3.1 |
| D-RV6 | 发布物提供时序、路线、街景或多视角信息时，解析时间和组关系 | 时间字段、时区、序列/路线成员、断链、重复成员和组重建率 | 关系组能够由公开规则唯一重建；不适用时为 `N/A` | C2.2、C2.6 |
| D-RV7 | 对影像、资产台账、空间几何和其他来源执行跨表连接 | 连接键、基数、一致连接数、悬空记录、冲突连接和关系图 | 所有声明的必需关系均可执行，异常基数有明确语义；不适用时为 `N/A` | C2.2、C3.1 |
| D-RV8 | 如存在官方划分，按观测或发布方声明的组级规则重建 | 划分 ID、缺失 ID、重复归属、分组字段和配置散列 | 官方划分能够唯一重建；本项不评价划分的工程域隔离质量 | C2.5 |
| D-RV9 | 将 `S_probe_asset` 转换为最小中立城市资产对象，并执行读取、索引、关系遍历和批供给 | 对象数、字段缺失、适配器日志、阻塞和修复 | 无未公开知识即可取得任务所需媒体、标签、身份、空间和关系字段 | C4.1、C4.2、C4.4 |
| D-RV10 | 相同输入、环境和配置下重复生成中立对象及关系图 | 清单散列、对象散列、关系边差异和顺序差异 | 除预先声明的非确定字段外，两次输出一致 | C4.3 |
| D-RV11 | 存在公开检测、分割或资产关联基线声明时，核对任务、版本、划分、预处理和指标并执行条件性复现 | 声明映射、日志、结果和容差裁决 | 满足主协议冻结的条件性复现规则；无声明时为 `N/A` | C3.3—C3.5 |

## 6. 任务专用解析规则

### 6.1 D-Det

- 明确检测框格式、坐标原点、归一化和边界约定；
- 明确 crowd、忽略、遮挡、截断和无目标影像；
- 明确类别与资产实例的区别。

### 6.2 D-Seg 与 D-InsSeg

- 明确背景、忽略值、类别 ID、实例 ID 和重叠规则；
- 明确像素掩膜、多边形、RLE 或其他几何编码；
- 明确缩放、裁剪和方向变换对标签的影响。

### 6.3 D-Link

- 资产 ID 必须声明唯一性作用域，例如全局、城市内或批次内；
- 观测、资产、路线、时间和空间几何之间的关系必须有明确基数；
- ID 相同但来自不同命名空间时不得静默合并；
- 同一资产多视角和多时相记录必须能够区分“同一身份”与“重复文件”。

## 7. 状态裁决与异常处理

- 只有二维匿名影像且未声明资产身份时，D-RV4、D-RV5、D-RV6 或 D-RV7 可按实际情况记为 `N/A`。
- 发布方声称可进行资产级或地理关联但关键 ID、CRS 或关系表缺失时，不得记 `N/A`，应按证据记 `FAIL` 或 `UNKNOWN`。
- 坐标只能靠城市名称、文件夹或外观猜测时，空间核验不能通过。
- 媒体可读取但标签、资产或关系记录串号时，相关执行项记为 `FAIL`。
- 第三方补建 ID 映射、CRS 或关系表时，必须保留原始阻塞、修复产物和摩擦记录。

## 9. 禁止做法

- 将 D-Det、D-Seg、D-InsSeg 和 D-Link 混成一次“总体可用”判断；
- 根据文件名或空间邻近猜测资产身份并判为通过；
- 把媒体可打开等同于资产关系可重建；
- 把 CRS 字段存在等同于定位质量满足工程要求；
- 静默合并不同城市、批次或命名空间中的同名 ID；
- 用第三方补建的关系表覆盖原始发布物失败；
- 将城市覆盖、小目标覆盖、标注准确率、捷径风险或模型性能写入 DRRL 等级计算；
- 使用目标工程案例选择身份、空间关联或复现规则。
