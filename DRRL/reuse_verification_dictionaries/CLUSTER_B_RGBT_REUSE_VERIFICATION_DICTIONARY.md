# Cluster B 复用核验字典：RGB–Thermal 配对数据

## 0. 文档角色与边界

本字典落实 DRRL 主协议中的 C2.6 和 C4.2，用于核验独立第三方能否正确识别、配对、解析并联合接入 RGB 与 Thermal 数据。

DRRL 在本字典中只判断配对、坐标、时间和热数据语义是否可解释并可执行，不判断：

- 配准误差是否足以支持工程部署；
- 同步抖动是否满足特定工程容差；
- 热数据或标注质量是否足以支持迁移；
- 融合模型是否优于单模态模型。

这些属于独立 ERL 或模型实验。

## 1. 适用范围

适用于同一资产、场景或事件的成对 RGB 与 Thermal 观测，用于共同的分类、检测或分割任务。

以下情况不属于本字典：

- 只有单一模态；
- 两种模态没有可声明的样本级或组级对应关系；
- Thermal 仅用于独立环境统计而非配对任务；
- 数据实质为可见光伪彩色或其他非热模态，但被错误命名为 Thermal。

超出范围时输出 `UNRATED_OUT_OF_SCOPE`，不得因缺少配对模态而判为低 DRRL。

## 2. 评级前冻结项

至少冻结：

1. 配对样本的定义和主键；
2. RGB 与 Thermal 文件类型、位深、通道和解码库；
3. Thermal 数据类型：辐射温度、原始计数、归一化强度或伪彩色；
4. 标签参考模态；
5. RGB、Thermal 和标签所在的坐标基准；
6. 裁剪、缩放、畸变校正、配准和投影变换链；
7. 时间戳、帧号和同步语义；
8. 缺失模态、重复帧和一对多关系的处理；
9. 官方划分及序列/资产分组方式；
10. 确定性探针配对集 `S_probe_pair` 和中立评价环境。

## 3. 最小中立数据对象

```yaml
pair_id:
rgb_uri:
thermal_uri:
annotation_uri:
task_subtype:
reference_modality:
rgb_shape:
thermal_shape:
thermal_data_type:
thermal_unit:
timestamp_rgb:
timestamp_thermal:
pairing_key:
spatial_transform:
split:
source_group_id:
```

不存在或不适用的时间、温度单位、空间变换等字段必须明确为 `N/A`，不能用空字符串掩盖其语义。

## 4. 执行范围与抽样

- 配对主键唯一性、左右模态引用和划分归属优先对完整清单执行全量核验。
- 载荷与联合变换通过冻结的 `S_probe_pair` 执行；探针集必须覆盖所有热数据类型、文件格式、任务分支、划分和声明的配准路径。
- 如存在一对多、多对一或缺失模态情况，必须纳入探针集，不能只抽取完整的一对一样本。
- 无法全量获取时，记录可访问分片、未获取分片和抽样规则，不得把局部成功外推为全量成功。

## 5. 条件核验项

| 核验 ID | 核验对象与执行操作 | 原始输出 | 通过规则 | 对应主判据 |
|---|---|---|---|---|
| B-RV1 | 识别 RGB 与 Thermal 的文件角色、格式和内容类型 | 各模态文件数、格式、位深、通道、无法识别文件和角色冲突 | 每个必需文件能够依据公开规则确定模态身份；不存在把伪彩色或普通 RGB 静默当作辐射数据的情况 | C2.2、C2.3 |
| B-RV2 | 按冻结配对键建立配对清单并核验键唯一性与基数 | 完整配对数、缺失模态数、重复键数、一对多/多对一数量、配对解析率 | 配对关系能够由公开规则唯一重建；异常基数有明确语义 | C2.2、C2.4、C2.6 |
| B-RV3 | 在中立环境中联合解码 `S_probe_pair` | RGB/Thermal 解码成功率、形状、位深、数值范围、失败清单 | 所有必需格式均可读取，且实际数据类型与声明一致 | C2.3、C2.4 |
| B-RV4 | 解析标签参考模态和 RGB—Thermal—标签坐标变换链，并执行一次往返映射 | 参考坐标、变换矩阵链、映射产物、无法执行变换数 | 标签所在坐标可唯一确定；已声明变换可按公开顺序执行 | C2.2、C2.3、C2.6、C3.1 |
| B-RV5 | 解析时间戳、帧号、时区和同步语义 | 时间字段、单位、差值计算结果、缺失或冲突记录 | 发布声明涉及同步时，第三方能够计算并解释模态时间关系；本项不判断工程容差是否充分 | C2.3、C2.6 |
| B-RV6 | 解析热数据物理或显示语义 | 数据类型、单位、缩放/偏移、无效值、伪彩色映射、辐射元数据引用 | 第三方能够区分温度、原始计数、归一化强度和伪彩色；声明的转换可执行 | C2.3、C3.1 |
| B-RV7 | 核验缺失模态、坏帧、重复帧和异常配对的表示规则 | 异常清单、状态编码、过滤规则和受影响配对数 | 异常状态能够被确定性识别和处理，不会静默错配 | C2.2、C3.6 |
| B-RV8 | 如存在官方划分，按配对或发布方声明的组级规则重建 | 各划分 pair ID、跨划分重复 ID、分组字段和配置散列 | 官方划分可唯一重建；RGB 与 Thermal 不会被拆入不同划分 | C2.5 |
| B-RV9 | 构建最小中立配对对象并执行联合读取、索引和批供给 | 对象数、字段缺失、联合加载日志、阻塞和修复 | 无未公开知识即可取得正确的双模态载荷、标签和关系字段 | C4.1、C4.2、C4.4 |
| B-RV10 | 相同输入、环境和配置下重复生成配对对象 | 清单散列、配对顺序、变换输出和字段差异 | 除预先声明的非确定字段外，两次输出一致 | C4.3 |
| B-RV11 | 存在公开融合或单模态基线声明时，核对模态、版本、划分、预处理和指标并执行条件性复现 | 声明映射、日志、结果和容差裁决 | 满足主协议冻结的条件性复现规则；无声明时为 `N/A` | C3.3—C3.5 |

## 6. 关键语义规则

### 6.1 配对不是文件名相似

配对必须来自公开的配对清单、资产/场景 ID、同步帧号、时间戳或可重复生成的规则。仅按排序、相邻编号或文件名相似度推断配对，不能判为通过。

### 6.2 可执行配准不等于配准质量充分

DRRL 通过条件是坐标基准和变换链可解释、可执行。变换残差、视差和工程容差由 ERL 条件判据评价。

### 6.3 Thermal 语义必须显式

- 辐射温度数据需要说明单位、缩放、偏移和无效值；
- 原始计数需要说明解码和转换条件；
- 归一化强度不能称为温度；
- 伪彩色图必须说明颜色映射，且不能静默当作单通道热测量。

### 6.4 缺失模态必须可观察

缺失模态必须通过状态字段、显式空引用或公开的异常清单表示。复制另一模态、填充全零或跳过样本而不记录，均不能判为可核验复用。

## 7. 状态裁决与异常处理

- 两种模态均可单独读取但配对无法重建时，B-RV2 为 `FAIL`。
- 配准参数存在但坐标约定或执行顺序未知时，B-RV4 为 `UNKNOWN`，不能凭可视化猜测通过。
- 未声明同步能力的静态配对数据，B-RV5 可为 `N/A`；声称同步但无法解释时间字段时不得记 `N/A`。
- 仅提供伪彩色图且明确用于语义识别，可以完成相应复用核验；不得据此声称可进行温度测量。
- 第三方修复配对表或变换链时，必须保留原始失败和摩擦记录。

## 9. 禁止做法

- 依据文件名相似或排序位置猜测配对并判为通过；
- 把伪彩色热图称为温度真值；
- 将配准可执行等同于配准误差足够低；
- 将同步字段存在等同于同步精度满足工程要求；
- 只验证两个独立单模态加载器而不验证联合对象；
- 用修复后的配对清单覆盖原始发布物的失败；
- 将融合收益、单模态支配或迁移性能写入 DRRL 等级计算；
- 使用目标工程案例决定配对、配准或复现规则。
