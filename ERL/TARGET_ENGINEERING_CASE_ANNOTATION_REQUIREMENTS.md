# ERL 独立目标工程案例标注数据要求

## 1. 目的与构念边界

本文档规定用于 ERL 阈值开发和独立预测效度验证的目标工程案例应如何
采集、标注、质控和冻结。

目标工程案例的标注结果只是 ERL 的外部效标，用于检验：

1. 不同 ERL 的源数据集在未见工程案例上的 zero-shot 表现是否呈预期方向；
2. 高 ERL 源数据集的跨案例表现是否更稳定；
3. 高 ERL 源数据集的尾部表现和灾难性失败风险是否更低。

目标工程案例不得：

- 进入源数据集的 ERL 计算；
- 用于事后修改已冻结的源数据集属性或判据状态；
- 用于选模型、早停、调超参数、选 checkpoint 或修改标签映射；
- 与源数据集存在对象、序列、地点或近重复泄漏。

因此，ERL 始终是目标案例出现之前的源数据集评价；目标案例只在后续
提供开发证据或独立验证证据。

## 2. 三个不可相互替代的样本量

标注计划必须分别确定以下三个样本量：

| 记号 | 统计对象 | 主要用途 |
|---|---|---|
| \(J\) | 独立目标工程案例数 | 估计跨案例均值、异质性、尾部表现和灾难性失败率 |
| \(n_j\) | 案例 \(j\) 内的有效独立评价单元数 | 控制单个案例性能终点的估计精度 |
| \(n_{a,j}\) | 案例 \(j\) 内独立重复标注审核单元数 | 估计标注错误、观察者差异和裁决不确定性 |

不得以同一案例内增加帧、切块、点、像素或同一资产的多视角数据替代增加
独立工程案例。

## 3. 独立目标工程案例

### 3.1 独立性定义

每个案例应对应一次可分离的工程来源或采集活动，例如不同项目、地点、资产
批次、采集任务或足以形成独立工程条件的时间窗。仅改变拍摄日期、取景位置
或同一项目中的连续路线，并不当然构成新案例。

必须在标注前冻结案例身份及其聚类字段：

- `case_id`；
- 项目、地点或资产批次识别字段；
- 采集时间窗；
- 传感器、平台和采集协议版本；
- 环境、材料、工况和尺度等应用范围字段；
- 用于防止案例间交叉的资产、序列、路线或扫描单元标识。

### 3.2 开发案例与独立验证案例

案例池必须按最高独立工程单元分为：

- **开发案例池**：允许用于估计方差、筛选指标、检验必要条件假设和形成
  候选切点；
- **独立验证案例池**：在 ERL 规则和 zero-shot 实验协议冻结后才启用，
  不得用于修改阈值、聚合逻辑或模型流程。

分池必须防止同一项目、资产、地点、序列或扫描单元跨池。如果开发后更改
任何实质性规则，原验证池不再是当前规则的独立验证池。

## 4. 案例内数据量计划

### 4.1 比例型终点的初始近似

对准确率、召回率、漏检率、失败率或标注错误率等比例型终点，在独立同分布
近似下，可使用：

\[
n_0=\frac{z_{1-\alpha/2}^{2}p(1-p)}{d^2}
\]

其中 \(p\) 为预期比例，\(d\) 为期望置信区间半宽，通常取 \(z_{0.975}=1.96\)。

| 预期比例 \(p\) | 95% 区间半宽 \(d\) | 独立单元近似数 \(n_0\) |
|---:|---:|---:|
| 0.50（最保守） | 0.05 | 385 |
| 0.50（最保守） | 0.03 | 1,068 |
| 0.10 | 0.05 | 139 |
| 0.10 | 0.03 | 385 |
| 0.10 | 0.02 | 865 |
| 0.10 | 0.01 | 3,458 |

上述公式只是计划起点。mIoU、mAP、AP、边界指标和点云区域指标的最终样本量
必须基于先导数据的簇结构、方差和类别发生率，通过簇级 bootstrap 或层级模拟确定。

### 4.2 簇内相关和设计效应

同一资产、序列、路线、扫描单元或地点内的观测不得默认独立。使用平均簇大小
\(m\) 和簇内相关系数 \(\rho\) 估计设计效应：

\[
\mathrm{DEFF}=1+(m-1)\rho, \qquad n_{clustered}\approx n_0\times \mathrm{DEFF}
\]

例如 \(m=5\)、\(\rho=0.20\) 时，\(\mathrm{DEFF}=1.8\)，385 个有效独立单元约对应 693 个原始
观测。正式分析的重采样和区间估计必须以资产、序列、场景或案例等最高独立
单元为单位，不得以像素、点或切片 bootstrap 产生虚假精度。

### 4.3 稀有类别与阳性对象

总样本量不能代替关键类别的独立阳性数。对预期召回率约为 0.80 的关键类别，
比例公式给出的初始近似为：

- 期望 95% 区间半宽约为 0.10：约 62 个独立阳性对象；
- 期望 95% 区间半宽约为 0.05：约 246 个独立阳性对象。

实际采集数应取总体精度需求、关键类别阳性量需求和簇设计效应调整后的最大值。
允许在采集或标注审核时对稀有类过采样，但必须保留抽样概率，并在总体终点中按
预注册方法还原或加权。

## 5. 独立案例数与可支持的结论

不设通用的固定案例数阈值。正式案例数由先导数据中的案例间方差、模型交互、
预期效应和计划声明的精度共同决定。

以下数值只用于解释案例数对结论边界的影响，不是 ERL 的经验阈值：

| 计划终点 | 案例数的直接影响 |
|---|---|
| 最差 10% 表现 | 10 个案例仅有 1 个案例进入最差 10%；20 个案例也只有 2 个 |
| 灾难性失败率（CFR）的观测粒度 | \(J=10\) 时为 10%；\(J=20\) 时为 5% |
| 零失败时的 CFR 上界 | “三法则”（Rule of Three）近似给出单侧 95% 置信上限 \(3/J\)；要将上界降至约 5%，需约 60 个独立案例且观测到零失败 |

当案例数不足时，禁止将单一最差案例作为稳定的 CVaR 或尾部风险估计报告。

## 6. 分阶段标注设计

### 6.1 先导阶段

每次只为一个 Cluster 中的一个冻结任务开展先导标注。可执行的初始预算为：

- 3 个独立目标工程案例；
- 每个案例以约 400 个有效独立评价单元为起点；
- 每个案例以约 140 个有效独立单元，由两名标注者在相互盲态下独立标注；
- 双人标注分歧全部进入专家或第三标注者裁决。

这些数值只是用于估计类别发生率、标注错误率、案例间方差和簇内相关的起始工作量。
3 个案例不得用于声称阈值已获得独立预测效度。

### 6.2 正式开发阶段

基于先导数据，估计：

- 案例间和案例内方差；
- 资产、序列、场景或扫描单元的簇内相关；
- 各关键类别的发生率和独立阳性对象数；
- 标注错误、漏标、边界偏差和几何差异的分布；
- 数据集、模型和案例间的交互方差。

使用上述参数进行层级模拟或基于簇的重采样功效分析，再确定正式开发池和独立
验证池的案例数、每案例数据量和重复标注量。

### 6.3 独立验证阶段

启用验证案例前必须冻结：

- ERL 指标、切点、证据角色和累积等级规则；
- 应用范围、标签映射和灾难性失败定义；
- 模型集合、训练预算、随机种子、数据处理和 checkpoint 规则；
- 主要终点、次要终点、重采样层级和统计模型；
- 标注规范、质控协议和不确定样本处理方式。

独立验证结果只用于支持、限定或证伪冻结规则，不用于即时修改该版规则。

## 7. Cluster 特定的独立评价单元

| Cluster | 当前范围 | 最高独立单元 | 不得作为顶层独立复制 |
|---|---|---|---|
| A | 二维基础设施表面/结构病害影像 | 结构、构件、资产或采集批次；其内保留原始影像 | 像素、裁剪块、同一资产的连拍影像 |
| B | RGB–Thermal 配对多模态巡检 | 资产、巡检序列或飞行/采集任务；其内保留 RGB-T 对 | 单模态帧、已拆散的 RGB/T 文件、同序列连续帧 |
| C | 三维城市/基础设施点云 | 场景、空间采集单元、独立扫描任务或资产 | 单个点、空间切块、同一扫描的密集子块 |
| D | 城市场景与城市资产识别 | 城市、路线段、资产、场景或采集任务，按冻结任务确定 | 像素、检测框、同一路线的连续帧 |

同一 Cluster 内不同任务必须分开设计和验证。例如 Cluster D 的语义分割和目标检测
不得共用一个性能终点或合并为一个效度结论。

## 8. 标注协议与质量控制

### 8.1 标注前冻结

必须在正式标注前冻结：

- 类别本体、层级和标签映射；
- 标注对象、最小可标尺寸和分裂/合并规则；
- `positive`、`negative`、`ignore`、`uncertain` 和范围外对象的处理；
- 检测框匹配、分割边界、遮挡、截断、模糊区和不可见区规则；
- RGB-T 模态身份、配对、配准和缺失模态规则；
- 点云坐标、单位、类别边界和运动/配准异常处理；
- 标注软件、导出格式、版本和审计日志要求。

先导期可修改标注指南。指南冻结后，先导标注要么按冻结规则重标，要么排除出
正式效标。

### 8.2 重复标注和裁决

重复标注审核集必须：

1. 按案例、关键类别、环境条件和簇结构分层抽样；
2. 由两名标注者在相互盲态下独立标注；
3. 由专家或第三标注者裁决分歧；
4. 保留两份原始标注、分歧记录、裁决结果和时间戳；
5. 禁止用裁决结果覆盖或删除原始标注。

如果需要估计标注者内部一致性，另行抽取时间隔离的重复标注集，不与标注者间
一致性审核并入同一指标。

### 8.3 任务特定错误分解

| 任务 | 至少分开报告的标注误差 |
|---|---|
| 分类 | 类别混淆、不确定类别、范围外类别并入 |
| 目标检测 | 漏标、虚假对象、类别错误、几何/框边界差异 |
| 语义/实例分割 | 类别错误、区域遗漏、实例分裂/合并、边界和面积差异 |
| RGB-T 任务 | 上述误差加模态身份、帧配对、空间配准和时间同步错误 |
| 三维点云 | 上述误差加对象切分、空间边界、坐标/单位和配准问题 |

## 9. 标注质量报告与敏感性分析

不得只用一个一致性分数代替标注质量报告。至少报告：

- 审核覆盖率及其簇级有效样本量；
- 原始一致率和类别级混淆矩阵；
- 漏标率、虚假对象率、类别错误率及其区间估计；
- 检测框、分割区域或点云边界的几何差异分布；
- 适用任务下的 Kappa、ICC 或其他一致性统计量及其置信区间；
- 裁决率、`uncertain` 率和范围外样本率；
- 逐案例、逐类别和逐主要环境子组的质量指标。

主分析使用裁决后的冻结共识标注。必须预注册以下敏感性分析：

1. 分别以两名原始标注者的标注为效标重新计算终点；
2. 以裁决共识为效标计算主结果；
3. 按实测类别混淆、漏标和边界误差分布扰动标注；
4. 在资产、序列、场景或案例层级重新抽样；
5. 检查候选 ERL 切点、数据集排序、等级方向和失败率结论是否改变。

如果在合理标注误差扰动下，候选切点、等级差异或尾部风险结论发生实质改变，
相应阈值必须标记为不稳定，不得冻结为 ERL 正式切点。

STAPLE 可作为多分割者共识估计的敏感性分析方法，Dawid–Skene 可作为无直接真值时的
潜在观察者误差模型。二者均不得在未核查假设时代替专家裁决。

## 10. 数据集组织、追溯与冻结

每个标注版本必须保留：

```text
target_case_release/
├── CASE_CARD.md
├── ANNOTATION_GUIDE.md
├── manifests/
│   ├── cases.tsv
│   ├── units.tsv
│   ├── clusters.tsv
│   ├── sampling.tsv
│   └── splits.tsv
├── annotations/
│   ├── annotator_a/
│   ├── annotator_b/
│   └── adjudicated/
├── qc/
│   ├── disagreements.tsv
│   ├── confusion_matrices/
│   ├── uncertainty_report.md
│   └── annotation_quality.json
├── provenance/
│   ├── source_checksums.tsv
│   ├── tool_versions.txt
│   └── changelog.md
└── RELEASE_MANIFEST.json
```

`units.tsv` 应至少包含 `case_id`、`unit_id`、`cluster_id`、`asset_or_sequence_id` 和
`source_uri_or_hash`，并记录采集时间、传感器/平台标识、环境分层、抽样概率、
标注状态、审核状态和排除原因。

发布前必须：

- 对原始数据、清单、标注、裁决结果和协议文件生成校验和；
- 对版本和修改记录建立不可变引用；
- 完成源数据集与目标案例间的对象、序列和近重复泄漏审核；
- 冻结案例池角色（开发或独立验证）；
- 记录原始样本数、有效独立样本数、簇大小分布和排除流程。

## 11. 标注数据接受标准

只有同时满足以下条件的标注数据，才可进入 ERL 正式开发或独立验证：

1. 应用范围、任务、标签映射和灾难性失败定义已预注册；
2. 案例、资产、序列和评价单元的层级关系可复算；
3. 开发与独立验证案例无最高独立单元交叉；
4. 标注规范和裁决程序已冻结；
5. 重复标注的抽样框、覆盖率、原始分歧和裁决结果齐全；
6. 标注误差及其区间估计已报告；
7. 源数据集与目标案例的泄漏审核通过；
8. 发布清单、校验和、版本和软件环境可追溯；
9. 主效标及其簇级统计方法已冻结；
10. 不存在利用目标案例调整模型、训练或 ERL 评级证据的行为。

未达到上述接受标准的数据可用于标注指南修订或探索性分析，但不得进入冻结的
预测效度结论。

## 12. 当前未冻结项

以下内容必须经先导数据估计和正式设计后冻结，不得由本文档的说明性数字直接推得：

- 各 Cluster 和任务的正式案例数；
- 各案例正式标注量和重复标注量；
- 关键类别的最低独立阳性对象数；
- 标注质量通过阈值；
- 灾难性失败阈值和可接受的失败率；
- 跨案例最差分位数和稳定性终点；
- 标注误差对 ERL 切点的实质性影响界值。
